# ЛР3. Метрики

## 1. Постановка
Вимірювати час задач, джитер, завантаження CPU, затримку реакції на подію, глибину стека у super loop прошивці.

## 2. Методика
- DWT CYCCNT для часу задач (min/avg/max).
- Мітки часу подій у кільцевому буфері RAM (EVT-лог).
- Проби GPIO PA4, PB0, PB1, PB10 для логічного аналізатора.
- Stack painting для вимірювання стека.
- parse_evt.py для обробки логів на хості.

## 3. Сценарії прогонів
S1 — простої (без подій).

S2 — номінальний режим (планувальник працює).

S3 — події і кнопки під час роботи.

S4 — стрес (довга операція + події + команди).
